# Codex 接入 API 中转站教程

> 适用于本仓库的 Codex Desktop macOS Patched 版本。
> 中转站可以将各类大语言模型统一转换为 OpenAI 兼容接口，方便国内用户使用。

---

## 📖 什么是中转站

**API 中转站**（又称 API 网关/代理）是一个统一的 AI 模型聚合与分发平台。它：

- 将各种大模型（OpenAI、Claude、Gemini 等）统一转换为 **OpenAI 兼容接口**
- 提供国内可直接访问的接入地址（无需科学上网）
- 支持按量计费，无需美元支付
- 通常提供比官方更低的价格

## 🚀 快速配置（一键脚本）

安装好本仓库的 Codex 后，只需执行：

```bash
# 使用默认中转站（BoLu_AI）
bash scripts/setup-relay.sh

# 或指定其他中转站地址
bash scripts/setup-relay.sh https://your-relay-server.com
```

此脚本会自动：
1. 备份旧的 `~/.codex/config.toml`
2. 写入中转站的 API 地址和模型提供商配置
3. 设置默认模型提供商

完成后，你只需在 Codex 的 Settings 中填入 API Key 即可使用。

## 📋 手动接入步骤

### 第一步：注册并获取 API Key

1. 打开 [https://boluotoken.com](https://boluotoken.com)
2. 点击右上角 **登录** → 使用 **GitHub** 登录或邮箱注册
3. 登录后进入 **控制台**
4. 在 **令牌** 页面点击 **添加令牌**，创建一个 API Key
5. 复制生成的 API Key（形如 `sk-xxxxx`）

### 第二步：充值

1. 进入控制台的 **充值** 页面
2. 选择充值金额（支持支付宝/微信）
3. 充值后即可使用

### 第三步：在 Codex Desktop 中配置

#### 方式一：使用配置脚本（推荐）

```bash
# 一键配置中转站地址
bash scripts/setup-relay.sh

# 然后打开 Codex，在 Settings 中填入 API Key 即可
open /Applications/Codex.app
```

#### 方式二：通过命令行启动

```bash
# 设置环境变量启动（适用于任何中转站）
OPENAI_BASE_URL="https://boluotoken.com" \
OPENAI_API_KEY="sk-你的key" \
  open /Applications/Codex.app
```

## 💡 常见问题

### Q: Codex 没有显示 Base URL 配置项？

部分 Codex 版本未开放 API Base URL 的 UI 设置项。可以尝试：

- 以命令行方式启动（方式二）
- 或者在 `~/.zshrc` 中设置环境变量：
  ```bash
  export OPENAI_BASE_URL="https://boluotoken.com"
  ```
- 某些中转站可能需要在 URL 后加 `/v1` 路径：
  ```bash
  export OPENAI_BASE_URL="https://boluotoken.com/v1"
  ```

### Q: 连接失败 / SSL 错误？

- 确认中转站地址是否以 `https://` 开头
- 尝试在浏览器中直接访问中转站地址，确认是否可打开
- 某些中转站需在 URL 末尾添加 `/v1`

### Q: 提示 "Invalid API Key"？

- 确认 API Key 是从中转站控制台复制的，不是 OpenAI 官网的
- 确认 API Key 没有过期
- 确认账户余额充足

### Q: 哪些中转站支持 Plugins 功能？

本仓库的补丁已为 API Key 用户启用 Plugins 入口。但插件能否正常工作还取决于：
1. 中转站是否支持插件相关 API
2. 所用模型是否支持插件功能
3. 建议联系中转站客服确认

## ⚠️ 注意事项

- **API Key 安全**：不要将 API Key 提交到公共代码仓库
- **网络稳定**：中转站的可用性取决于服务商，建议选择信誉良好的服务
- **价格对比**：不同中转站价格不同，使用前请对比各模型价格
- **合规使用**：请遵守中转站的使用条款和 OpenAI 的使用政策
